# Student Wellbeing Statistical Analysis & Probability

## Description
A Python statistical analysis project based on a Student Wellbeing Survey dataset. The notebook applies descriptive statistics, outlier detection, probability concepts, Bayes' theorem, independence testing, and normal distribution analysis.

## Analysis Performed

- Mean, median, and mode
- Range, variance, and standard deviation
- Q1, Q3, and IQR
- Greatest variability analysis
- IQR-based outlier detection
- Before and after outlier comparison
- Probability of Events A, B, C, and D
- Union and intersection probabilities
- Conditional probabilities
- Mutual exclusivity of Year 1 and Year 4
- Independence test for Events A and B
- Bayes' theorem calculation and verification
- Academic Readiness Score normal distribution analysis
- Z-score calculation and interpretation
- 68–95–99.7 empirical rule
- Five meaningful statistical observations

## Events Used

- **Event A:** Part-Time Job = Yes
- **Event B:** Stress Score ≥ 7
- **Event C:** Scholarship = Yes
- **Event D:** Exercise ≥ 3 days per week

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
